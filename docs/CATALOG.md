# Community catalog listing

**Name:** ClickUp Tasks

**Description (≤ 120 chars):**
Your ClickUp tasks in Orca's sidebar: browse, read and edit tasks, checklists and comments.

**Highlights**

- See the ClickUp tasks assigned to you in a sidebar panel, with filters and presets.
- Browse any Space, Folder and List of your Workspace.
- Edit status, priority, dates, assignees, tags and the description in place.
- Manage checklists, subtasks and comments (replies, @mentions, resolve).
- Token stays in the OS keychain; only two permissions (secrets, storage); no telemetry.
