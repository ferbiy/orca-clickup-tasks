# Community catalog listing

**Name:** ClickUp Tasks

**Description (≤ 120 chars):**
Your ClickUp tasks in Orca's sidebar. Start one in its own worktree with your agent, then update ClickUp.

**Highlights**

- See the ClickUp tasks assigned to you in a sidebar panel.
- Start a task in a dedicated worktree and branch, with your coding agent briefed on it.
- Get notified when the agent finishes, then open the workspace to review.
- Update status and post a comment only when you press Update task.
- Token stays in the OS keychain; task text is fenced as untrusted data; no telemetry.
